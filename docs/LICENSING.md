# Licensing decision required

The supplied manuscript artefacts do not state an author-approved public licence. The repository therefore does not silently grant reuse rights.

Before public release, the authors should approve an explicit licensing policy. A common open-science arrangement is:

- Apache-2.0 or MIT for Python, SML, and CPN model source;
- CC BY 4.0 for data, documentation, figures, and manuscript-derived supplementary material;
- third-party Elsevier template files excluded from the repository licence and covered by their own terms.

Replace the root `LICENSE` only after all authors approve the selected terms.
