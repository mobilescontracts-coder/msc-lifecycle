# Metric Definitions

- **Finality success** = finality certificates / submitted transactions.
- **Receipt success** = receipts / submitted transactions.
- **Logical CPN throughput** = completed outputs per abstract model-time interval.
- **Prototype receipts/s** = receipts produced / measured wall-clock interval.
- **Cross-shard ratio** = cross-shard transactions / submitted transactions.
- **Shard-load imbalance** = standard deviation of shard load.
- **Reward Gini**: inequality of validator reward distribution; lower is more even.
- **Reward HHI**: concentration of validator reward shares; lower is less concentrated.
- **Nakamoto coefficient**: smallest number of actors whose cumulative share reaches the configured control threshold; higher indicates a more distributed control threshold.
- **Owner concentration**: share attributed to the most influential owner or configured owner-level concentration measure.

Logical CPN time and wall-clock implementation time are not directly comparable.
