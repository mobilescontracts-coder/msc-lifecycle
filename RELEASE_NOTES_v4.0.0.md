# SPoS-MSC v4.0.0 reproducibility release

This release establishes the public v3 → v4 artefact sequence and provides the complete supplied native CPN analysis package.

## Included

- public v3 predecessor self-logging CPN;
- public v4 sensitivity-enabled hierarchical CPN;
- declaration, smoke, pilot, Q1–Q7 and OFAT CPN ML scripts;
- 2-, 72-, 700-, and 2,400-row native CSV matrices;
- validation and statistical-analysis pipeline;
- exact reference outputs and manuscript figures/tables;
- Overleaf-ready Elsevier CAS manuscript and deterministic 32-page PDF;
- tests, GitHub Actions, checksums, citation metadata, and release documentation.

## Important boundaries

- CPN throughput is a logical completion rate, not public-network TPS.
- The sensitivity study is local and one-factor-at-a-time.
- The runtime-emulator source/raw runs and native CPN replication folders are not in the supplied source package.
- The public reuse licence requires author approval before archival release.
