# Native CPN Tools monitor exports

Place the unmodified native CPN Tools exports used by the submitted manuscript
in this directory. Recommended naming:

```text
Q1_run_001_monitors.csv
...
Q7_run_100_monitors.csv
```

Also include:

- the monitor definitions or CPN ML monitor code;
- the exact model SHA-256;
- CPN Tools version;
- scenario identifier, run identifier, and seed;
- export timestamp and command/procedure;
- a manifest mapping each export to the manuscript result row.

The current repository package contains no native exports. This directory is a
release blocker if the manuscript claims native CPN Tools simulation results.
