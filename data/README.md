# Data catalogue and provenance

The repository separates raw evidence by origin. Do not merge or relabel these
categories.

## `raw/cpn_proxy/`

These Q1–Q7 output matrices reproduce the manuscript headline values:
192,404 routed transactions, 173,089 finality certificates, and 170,369
receipts. Their embedded README states that they were generated by a
model-faithful Python execution of the integrated CPN transition semantics,
not by native CPN Tools monitors.

## `raw/cpn_native/`

Reserved for the unmodified native CPN Tools monitor exports used in a final
journal release. This directory currently contains instructions only.

## `raw/internal_baseline_proxy/`

Separate proxy/emulation workbooks for six controlled policy variants,
including the Qtum-style single-chain path, static sharding, stake-only PoS,
random committee selection, SPoS without adaptive routing, and full SPoS-MSC.
These are retained for internal baseline and ablation development and are not
the source of the manuscript's 192,404-transaction headline result.

## `raw/prototype/`

Run-level and aggregate outputs from the tested Python prototype and controlled
local API benchmark.

## `processed/`

Precomputed tables used during manuscript drafting. Reproduced versions are
written by the scripts in `analysis/` to `outputs/reproduced/`.
